# Cafe Inventory Management System — Frontend (AWS)

Angular dashboard for a full-stack cafe inventory management system, deployed to AWS via S3 + CloudFront. This is the AWS-deployed variant of [cafe-inventory-frontend](https://github.com/rrich360/cafe-inventory-frontend) — same application code and history, prepared and deployed for the cloud.

## Live app

https://d2hze0x3um3sp2.cloudfront.net, served from a private S3 bucket through CloudFront. It talks to the live AWS backend ([cafe-inventory-backend-aws](https://github.com/rrich360/cafe-inventory-backend-aws)) over HTTPS through a second CloudFront distribution.

New accounts start with their own sample order history, so you can sign up and try AI Order Insights right away.

## Features

- **AI Order Insights**: one click turns your stock orders into a plain-language summary (what's overdue, how spending is trending, what to reorder next), generated by Claude Haiku 4.5 on Amazon Bedrock.
- Stock orders with downloadable PDFs, product and category management, and an admin role.
- Built to work on phones: tables stack into labeled rows, and the navigation adapts to small screens.

## Deploying

```
ng build --configuration production
aws s3 sync dist/Frontend s3://<your-bucket> --delete
aws cloudfront create-invalidation --distribution-id <your-distribution-id> --paths "/*"
```

## Tech stack

- Angular 14.2 + Angular Material
- RxJS
- JWT auth via an HTTP interceptor

## Getting started

1. Install dependencies:
   ```
   npm install
   ```
2. Point `src/environments/environment.ts` (`apiUrl`) at your backend — either the local baseline (`http://localhost:8081`) or the live AWS deployment.
3. Run the dev server:
   ```
   ng serve
   ```
4. Navigate to `http://localhost:4200`.
